# DNS Threat Detection using Zeek and Python

## Overview

This project analyzes DNS network traffic using Zeek and Python to identify potentially suspicious DNS queries.

Zeek processes network traffic and generates structured DNS logs. A Python script then analyzes the `dns.log` file and checks DNS queries for predefined suspicious patterns.

The project supports both offline PCAP analysis and live network traffic monitoring.

## Technologies Used

- Zeek 8.0.5
- Python 3
- Ubuntu Linux
- VMware Workstation
- Git and GitHub

## Detection Logic

The Python script reads DNS queries from Zeek's `dns.log` and checks them for predefined suspicious strings such as:

- xn--
- base64
- cmd
- powershell
- malware
- tunnel
- data

If a matching pattern is found, the script generates an alert.

Example:

Suspicious DNS query detected: malware.example.com

## Live Traffic Capture

Zeek can monitor the Ubuntu VM's network interface using:

sudo /opt/zeek/bin/zeek -C -i ens33

While Zeek is running, normal network activity such as web browsing generates traffic that Zeek analyzes.

Stop the capture using:

Ctrl + C

Zeek then produces logs such as:

- dns.log
- conn.log
- http.log
- ssl.log
- x509.log
- quic.log

## Running the DNS Detector

Move to the directory containing the generated `dns.log` file and run:

python3 ~/dns-threat-project/dns_alerts.py

For normal traffic, the program may display:

No suspicious DNS queries detected

If a suspicious pattern is found:

Suspicious DNS query detected: malware.example.com

## Safe Detection Test

A harmless test DNS query can be generated using:

nslookup malware.example.com

The word `malware` matches one of the predefined detection patterns.

Zeek records the DNS request in `dns.log`, and the Python detector identifies it.

## PCAP Analysis

The project can also analyze previously captured network traffic.

Example:

/opt/zeek/bin/zeek -r dns.pcap

Zeek processes the PCAP and generates `dns.log`, which can then be analyzed using the Python detection script.

## Project Files
